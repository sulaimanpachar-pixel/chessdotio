# Chessdotio ♟️

An interactive, responsive two-player web chess platform featuring real-time game state evaluation and AI-assisted coaching powered by Google AI Studio / Gemini API.

---

## 🚀 Features

- **Interactive Chessboard:** Smooth drag-and-drop piece movement with legal move validation.
- **AI Coach Integration:** Real-time strategic feedback and position evaluation.
- **Game State Tracking:** Dynamic move history, captured pieces counter, and evaluation indicators.
- **Modern UI:** Clean, responsive dark-themed interface built for seamless desktop and mobile play.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript / React
- **Engine / Logic:** Chess logic integration & position evaluation
- **AI Backend:** Google AI Studio / Gemini API integration

---

## 📦 Getting Started

### 1. Clone the repository
\`\`\`bash
git clone https://github.com/sulaimanpachar-pixel/chessdotio.git
cd chessdotio
\`\`\`

### 2. Environment Configuration
Create a `.env` file in the root directory (if using an API key):
\`\`\`env
VITE_GEMINI_API_KEY=your_api_key_here
\`\`\`

### 3. Install & Run
\`\`\`bash
# Install dependencies
npm install

# Start local development server
npm run dev
\`\`\`
